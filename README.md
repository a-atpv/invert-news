# Новости invert.kz

Тексты раздела [«Новости»](https://invert.kz/news) сайта Invert, маркетплейса автозапчастей в Казахстане.

- Каждая новость лежит в `news/` отдельным файлом: `ГГГГ-ММ-ДД-слова-латиницей.md`. Имя файла без `.md` становится адресом новости на сайте.
- В начале файла, между двумя строками `---`: `title`, `summary`, `topic`, `source`, `source_url`. Дальше текст: абзацы, подзаголовки `## `, списки `- ` и `1. `, `**полужирный**` и `[ссылки](https://…)` на источник или государственные сайты.
- Без длинного тире («—», «–»): вместо него двоеточие, запятая, скобки или точка; диапазон и маршрут пишутся через дефис («10-20», «Алматы-Хоргос»).
- Проверка формата: `node scripts/check-news.js` (ничего ставить не нужно). Тире она тоже не пропускает.

Сайт забирает содержимое ветки `main` раз в несколько минут. Файл, который не читается как новость, на сайте не показывается; удалённый файл с сайта пропадает.

## Threads

Каждая новость отсюда выходит и в Threads Invert, [@invert.app](https://www.threads.com/@invert.app): заголовок, подводка, строка «Больше новостей для водителей Казахстана в приложении Invert» со ссылкой `invert.kz/download?source=threads_news` и карточка со ссылкой на статью на invert.kz (с меткой `utm_source=threads`). Публикует GitHub Actions: `.github/workflows/threads.yml` запускает `scripts/threads.js` в 09:00, 13:00 и 19:00 по Алматы, по одной статье за раз, сначала самые старые. Выходят только статьи за сегодня и вчера и не раньше дня старта (переменная `THREADS_SINCE`), архив не публикуется. Больше трёх постов в день не бывает.

- **Удалили файл** в `news/`: пост в Threads снимается через минуту-другую (запуск на каждый push в `news/`).
- **Исправили заголовок или подводку**: старый пост снимается, исправленный выходит в ближайший слот, если статья за сегодня или вчера. Исправление текста статьи ниже подводки пост не трогает.
- **Что уже вышло**, скрипт читает из самого Threads, по ссылке в карточке. Своих файлов состояния нет, повторов не бывает.
- **Остановить публикацию**: в Settings → Secrets and variables → Actions → Variables поменять `THREADS_MODE` с `live` на любое другое значение. Тогда скрипт только пишет в журнал, что сделал бы.
- **Посмотреть, что выйдет**, ничего не публикуя: Actions → Threads → Run workflow → `preview`. Там же `whoami` (чей ключ, какие права, когда кончается), `post` (опубликовать следующую сейчас), `sync`, `refresh`.

Настройки (Settings → Secrets and variables → Actions):

| Что | Где | Значение |
|---|---|---|
| `THREADS_TOKEN` | секрет | ключ Threads профиля @invert.app из приложения Meta с вариантом «Access the Threads API»; @invert.app в нём Threads Tester, проверка приложения у Meta не нужна |
| `THREADS_MODE` | переменная | `live` публикует, всё остальное пробный режим |
| `THREADS_SINCE` | переменная | день старта, `ГГГГ-ММ-ДД`: статьи раньше него не выходят |
| `THREADS_USERNAME` | переменная | профиль, куда публикуем (`invert.app`); ключ другого профиля скрипт не использует |
| `THREADS_TOPIC` | переменная | тема поста в Threads (`Авто`) |
| `GH_SECRETS_TOKEN` | секрет, по желанию | ключ GitHub с правом Secrets: write на этот репозиторий: нужен, только если Meta при продлении выдаёт новый ключ |

Ключ Meta живёт 60 дней. По понедельникам запуск `refresh` продлевает его ещё на 60. Если ключу осталось меньше 10 дней, запуски становятся красными, и GitHub присылает письмо: тогда нужен новый ключ (запуск `whoami` покажет срок).
