# Новости invert.kz

Тексты раздела [«Новости»](https://invert.kz/news) сайта Invert, маркетплейса автозапчастей в Казахстане.

- Каждая новость лежит в `news/` отдельным файлом: `ГГГГ-ММ-ДД-слова-латиницей.md`. Имя файла без `.md` становится адресом новости на сайте.
- В начале файла, между двумя строками `---`: `title`, `summary`, `topic`, `source`, `source_url`. Дальше текст: абзацы, подзаголовки `## `, списки `- ` и `1. `, `**полужирный**` и `[ссылки](https://…)` на источник или государственные сайты.
- Без длинного тире («—», «–»): вместо него двоеточие, запятая, скобки или точка; диапазон и маршрут пишутся через дефис («10-20», «Алматы-Хоргос»).
- Проверка формата: `node scripts/check-news.js` (ничего ставить не нужно). Тире она тоже не пропускает.

Сайт забирает содержимое ветки `main` раз в несколько минут. Файл, который не читается как новость, на сайте не показывается; удалённый файл с сайта пропадает.
